# Samsa v0.9.0: transactions, KIP-932 share groups, and v2 application fault verdicts

Production plan milestone v0.9 (`docs/PRODUCTION.md`, items 15, 22, 23b, and
Item 17 Kafka comparison benchmark).

## What is new

- **Transactions** (item 15, ADR 0035, format level 7, snapshot v12):
  `InitProducerId`, `AddPartitionsToTxn`, `AddOffsetsToTxn`, `TxnOffsetCommit`,
  `EndTxn`, `WriteTxnMarkers`, KIP-890 epoch bump, `read_committed` LSO tracking
  and aborted-transaction filtering. Tested with Apache Kafka Java 4.4.0
  transactional producer/consumer and `franz-go`. Report:
  `docs/reports/c15-transactions.md`.
- **Share groups (KIP-932)** (item 22, ADR 0034, format level 6, snapshot v11):
  `ShareGroupHeartbeat` (76), `ShareGroupDescribe` (77), `ShareFetch` (78),
  `ShareAcknowledge` (79), record-level acquisition locks, timeout redelivery,
  and delivery counts. Tested with Apache Kafka Java 4.4.0 share consumer and
  `kafka-share-groups.sh --describe`. Report: `docs/reports/c22-share-groups.md`.
- **Application fault testing for transactions, KIP-848, and share groups**
  (item 23b, ADR 0036): `-faults` injection and broker verdicts covering
  transactional pipelines, KIP-848 groups, and KIP-932 share groups. Report:
  `docs/reports/c23b-app-faults.md`.
- **Apache Kafka 4.4.0 comparison benchmark** (item 17, ADR 0040, G8/G10):
  reproducible head-to-head comparison (`make bench-kafka`) covering cold
  startup, RSS, page-cache vs fsynced produce throughput/latency, sequential
  consume, 10/100/500-partition scaling, and 3-node diskless storage. Report:
  `docs/reports/g8-kafka-comparison.md`.

## Upgrading from earlier releases

Rolling restart one node at a time with SIGTERM. Format levels 6 (share groups)
and 7 (transactions) raise automatically once every voter runs v0.9.0 or later.
