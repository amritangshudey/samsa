# Samsa v0.2.0: correct with default clients

Production plan milestone v0.2 (`docs/PRODUCTION.md`, items 1–3).

## What is new

- **Idempotent producer** (A2): retries across leader changes, resets and
  expiry write nothing twice. Java, franz-go and kcat run with idempotence
  on. Reports: `docs/reports/a2-idempotent-part-a.md`, `-part-b.md`.
- **Raft hardening** (B3): PreVote, CheckQuorum, leadership transfer, and
  a graceful stop on SIGTERM that hands leadership over. Report:
  `docs/reports/b3-raft-hardening.md`.
- **Operations** (B4):
  - Admin APIs, so the standard Kafka 4.4 CLI tools work: topics, configs
    (read-only), delete-records, consumer-groups, get-offsets and
    cluster-id.
  - Prometheus metrics, `/healthz` and `/readyz`.
  - `samsa check` for a stopped node's data.
  - A config file and a locked data directory.
  - Reports: `docs/reports/b4a-admin-apis.md`, `b4b-operations.md`.

## Upgrading from v0.1.0

The on-disk formats of the log and snapshot carry the new state (producer
state, partition starts). There is no tested upgrade path between
releases yet (item 10): start v0.2.0 on a fresh data directory.
