# Samsa v1.0.0

Samsa v1.0.0 completes the roadmap in `docs/PRODUCTION.md` (gates G1–G11,
items 1–24, with multi-Raft sharding deferred by ADR 0039 after follower fetch,
tiered object storage, and diskless topics).

## Highlights

- **Single static binary, zero external runtime dependencies** (standard library
  only in root `go.mod`), starting in ~30 ms with ~12 MiB idle RSS.
- **Deterministic simulation & exhaustive verification**: 3,000-seed simulator
  per CI run (30,000 nightly), depth-12 exhaustive Raft checker, 30+ deliberate
  mutation bugs caught, and black-box real-process chaos testing.
- **Application fault testing (`-faults`)**: reproducible Kafka-level fault
  injection and broker verdicts for classic consumer groups, KIP-848 consumer
  groups, KIP-932 share groups, and transactions.
- **Modern Kafka protocols**: idempotent producers, transactions (KIP-890),
  topic IDs, KIP-392 follower fetch, KIP-848 consumer groups, KIP-932 share
  groups, per-topic retention and key compaction, TLS/mTLS, SASL PLAIN &
  SCRAM-SHA-256/512, ACLs, online cluster membership changes, rolling upgrades,
  storage scrub and peer repair.
- **Unified object storage & diskless topics**: pluggable `ObjectStore`
  (`file://` and zero-dependency S3 SigV4) powering both tiered storage and
  per-topic `diskless.enabled=true` mode (97.7%–99.99% local Raft disk
  reduction).
- **Verified client compatibility matrix (`docs/compatibility.md`)**: generated
  from live tests across `twmb/franz-go`, `IBM/sarama`, `segmentio/kafka-go`,
  Apache Kafka Java 4.4.0, `kcat` (`librdkafka`), and Apache Kafka 4.4.0 CLI
  tools.
- **Honest benchmarks (`docs/reports/g8-kafka-comparison.md`)**: head-to-head
  comparison against Apache Kafka 4.4.0 KRaft documenting both strengths and
  trade-offs.

## Upgrading from v0.9.0

Rolling restart one node at a time with SIGTERM (`TestRollingUpgrade`). Format
level (9) and snapshot version (v13) are unchanged from v0.9.0.
