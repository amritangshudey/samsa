# Samsa v0.8.0: tiered object storage and diskless topics

Production plan milestone v0.8 (`docs/PRODUCTION.md`, items 20 and 21).

## What is new

- **Unified pluggable object storage / tiered storage** (item 20, ADR 0037,
  format level 8, snapshot v13): pluggable `ObjectStore` (`file://` local
  directory, zero-dependency stdlib S3 SigV4 client, and deterministic simulator
  fault store), `cmdTier` (`batchRef` with `logIndex == 0`), bounded in-memory
  remote batch cache (`-object-cache-bytes`), and two-pass garbage collection.
  Report: `docs/reports/c20-object-storage.md`.
- **Diskless topics** (item 21, ADR 0038, format level 9): per-topic
  `diskless.enabled=true` mode where any broker (leader or follower) uploads
  batch payloads directly to `ObjectStore` and commits an atomic `cmdAppendRef`
  (~97 bytes) via Raft with `objKey` deduplication. Cuts local Raft disk by
  97.7%–99.99% on 1–4 KiB batches. Report: `docs/reports/c21-diskless-topics.md`.
- **Sharding decision** (item 14, ADR 0039): defers multi-Raft sharding for v1.0
  after follower fetch (19), tiered storage (20), and diskless topics (21).

## Evidence

- 3,000-seed deterministic simulator under lost puts, lost gets, and torn reads
  on the object store: 0 failures (`TieredPuts: 111,467`, `TieredGets: 279,557`).
- Mutation `delete_local_segment_before_upload_confirmed` caught by 104/200 seeds.
- 3-node cluster integration tests (`TestTieredStorageCluster`,
  `TestDisklessTopicsCluster`) verified across restarts.

## Upgrading from earlier releases

Rolling restart one node at a time with SIGTERM. Format levels 8 (tiered
storage) and 9 (diskless topics) raise automatically once every voter runs
v0.8.0 or later.
